# المساعد الشخصي عبر تيليجرام ولوحة ويب

مشروع خاص لإدارة المهام والتذكيرات والملاحظات والروابط والملفات والدخل والمصروفات. الواجهة عربية ومتوافقة مع الهاتف، وخدمة البوت ولوحة التحكم تعملان من تطبيق Node.js واحد.

## الميزات

- مهام بمواعيد اختيارية وتذكير تلقائي عبر تيليجرام.
- ملاحظات مع البحث النصي.
- حفظ الروابط.
- تسجيل الدخل والمصروفات وحساب الرصيد.
- رفع الملفات من لوحة الويب أو إرسال المستندات والصور إلى البوت.
- لوحة ويب محمية بكلمة مرور، وجميع عمليات API والتحميل محمية بجلسة تسجيل الدخول.
- السماح بمعرّف تيليجرام واحد فقط باستخدام أوامر البوت وحفظ الملفات.
- تخزين البيانات في `db.json` والملفات في مجلد `files` ضمن مسار البيانات.

## أمان التوكن

إذا سبق لك إرسال توكن البوت في محادثة أو مستودع عام، ألغِه من `@BotFather` وأنشئ توكنًا جديدًا قبل النشر. لا تضع التوكن داخل ملفات JavaScript أو HTML ولا تحفظه في مستودع GitHub. أضفه فقط إلى متغير البيئة `TELEGRAM_BOT_TOKEN` في لوحة الاستضافة.

## النشر المقترح: GitHub + Railway

GitHub يحفظ الكود ويتيح لك تحديثه، لكنه لا يشغّل خدمة Node.js تعمل باستمرار بمفرده. استخدم استضافة تطبيقات مثل Railway لتشغيل البوت ولوحة الويب معًا. عنوان Railway العام يوفّر HTTPS للوحة الويب.

### 1. رفع المشروع إلى GitHub

1. نزّل ملف ZIP وفك ضغطه.
2. أنشئ مستودعًا جديدًا خاصًا (Private) على GitHub.
3. ارفع ملفات المشروع إليه. تأكد أن `.env` وبيانات المستخدم ليست ضمن المستودع؛ ملف `.gitignore` يستثنيهما.

### 2. إنشاء الخدمة في Railway

1. افتح لوحة Railway وأنشئ مشروعًا جديدًا من مستودع GitHub.
2. اختر هذا المستودع، ودع Railway يبني التطبيق ويشغّله باستخدام `npm start`.
3. من إعدادات الخدمة، أضف Volume، واجعل مسار الربط (Mount Path) هو `/data`.
4. أضف متغيرات البيئة التالية في خدمة Railway:

| المتغير | القيمة |
|---|---|
| `TELEGRAM_BOT_TOKEN` | التوكن الجديد الذي أنشأته عبر `@BotFather` |
| `TELEGRAM_OWNER_ID` | معرّفك الرقمي في تيليجرام؛ اتبع الخطوة التالية لمعرفة الرقم |
| `ADMIN_PASSWORD` | كلمة مرور طويلة وفريدة للوحة الويب |
| `SESSION_SECRET` | سلسلة عشوائية طويلة لا تقل عن 32 حرفًا |
| `DATA_DIR` | `/data` |
| `TIMEZONE` | `Africa/Khartoum` (أو المنطقة الزمنية المناسبة لك) |
| `CURRENCY` | `SDG` (يمكن تغييره إلى عملتك) |

يمكن ترك `PORT` دون ضبط؛ Railway يمرره تلقائيًا.

لإنشاء قيمة آمنة لـ `SESSION_SECRET` على جهازك، نفّذ:

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

لا تستخدم المثال أو كلمة مرور سهلة كقيمة حقيقية.

### 3. معرفة معرّف تيليجرام الشخصي

1. اترك `TELEGRAM_OWNER_ID` مؤقتًا فارغًا في إعدادات الخدمة ثم انشرها؛ بقية متغيرات البيئة يجب أن تكون مكتملة.
2. افتح البوت في تيليجرام وأرسل `/id`. سيرسل البوت الرقم الرقمي لحسابك.
3. أدخل الرقم كقيمة `TELEGRAM_OWNER_ID` في Railway ثم أعد النشر.
4. أرسل `/start` ثم `/help` إلى البوت.

إذا لم ترغب بترك الخدمة دون مالك محدد، يمكنك تنفيذ هذه الخطوة محليًا بعد ضبط التوكن وكلمة المرور، ثم نقل المعرف إلى Railway.

### 4. فتح لوحة التحكم

من إعدادات الخدمة في Railway أنشئ Public Domain. افتح عنوان HTTPS الذي توفره الخدمة وسجّل الدخول باستخدام `ADMIN_PASSWORD`. لا تشارك هذا العنوان مع الآخرين رغم وجود كلمة مرور.

### 5. التشغيل على مدار الساعة والتكلفة

للتذكيرات المستمرة، يجب أن تبقى عملية Node.js عاملة. خطة Railway المجانية تمنح رصيد استخدام محدودًا، وليست ضمانًا لتشغيل الخدمة على مدار الساعة. خطط Railway المدفوعة تبدأ عادةً من اشتراك شهري؛ راجع صفحة الأسعار الحالية قبل النشر. كذلك، لا تستخدم نظام ملفات مؤقتًا لتخزين `db.json` والملفات؛ Volume المثبت على `/data` مطلوب حتى لا تضيع البيانات عند إعادة تشغيل الخدمة.

## التشغيل محليًا

تحتاج إلى Node.js 20 أو أحدث.

```bash
npm install
cp .env.example .env
```

عدّل `.env` وأدخل التوكن الجديد وكلمة مرور لوحة الويب وسر الجلسة. شغّل:

```bash
npm start
```

افتح `http://localhost:3000`. لتحديد معرّف المستخدم، اترك `TELEGRAM_OWNER_ID` فارغًا مؤقتًا، شغّل الخدمة وأرسل `/id` للبوت. أدخل المعرف في `.env` ثم أعد تشغيل التطبيق.

## أوامر تيليجرام

```text
/start
/help
/id
/tasks
/addtask 2026-10-24 09:00 | مراجعة التقرير
/done معرف_المهمة
/deltask معرف_المهمة
/note نص الملاحظة
/notes كلمة للبحث
/delnote معرف_الملاحظة
/link https://example.com | عنوان الرابط
/links
/income 150000 | راتب
/expense 2500 | مواصلات
/balance
/files
```

أرسل صورة أو مستندًا أو ملف فيديو/صوت إلى البوت لحفظه في المساحة الخاصة. الحد الأعلى الافتراضي للملفات 20 ميغابايت، ويمكن تغييره عبر `MAX_UPLOAD_MB` إلى قيمة بين 1 و20.

## النسخ الاحتياطي

انسخ `db.json` ومجلد `files` من Volume `/data` دوريًا إلى مكان آمن. يتضمن `db.json` ملاحظاتك وروابطك وبياناتك المالية؛ لا ترفعه إلى مستودع عام. الملفات متاحة للتنزيل من لوحة التحكم بعد تسجيل الدخول فقط.

## ملاحظات فنية

- البوت يستخدم Telegram long polling؛ لا يلزم إعداد Webhook.
- لوحة الويب وواجهة API تستخدمان جلسة محمية وملفات تعريف ارتباط آمنة عند التشغيل خلف HTTPS.
- إذا شغّلت نسختين من الخدمة بنفس التوكن، فقد تتعارض عمليات polling. استخدم نسخة خدمة واحدة فقط.
- هذه نسخة شخصية مبسطة تخزن البيانات في JSON. لتعدد المستخدمين أو الاستخدام عالي الحمل، استخدم قاعدة بيانات فعلية مثل PostgreSQL.
